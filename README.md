# Sistema de Desconto Progressivo

## 🎯 Objetivo
Programa em Python que calcula descontos progressivos em compras online:

- Menor que R$200,00 → 5% de desconto  
- Entre R$200,00 e R$299,99 → 10% de desconto  
- A partir de R$300,00 → 15% de desconto
