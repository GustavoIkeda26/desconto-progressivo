# Sistema de Desconto Progressivo

## 🎯 Objetivo
Programa em Python que calcula descontos progressivos em compras online:

- Menor que R$200,00 → 5% de desconto  
- Entre R$200,00 e R$299,99 → 10% de desconto  
- A partir de R$300,00 → 15% de desconto  

---

## 🚀 Como executar

### Pré-requisitos
- Ter **Python 3** instalado
- Ter um editor como **Visual Studio Code**

### Passo a passo
1. Clone este repositório:
   ```bash
   git clone https://github.com/GustavoIkeda26/desconto-progressivo.git

2. Entre na pasta:
```bash

cd desconto-progressivo

3. Abra no VS Code e execute no terminal:
```bash
python desconto.py
ou, dependendo da instalação:
python3 desconto.py
Digite o valor da compra quando solicitado e veja o resultado com o desconto aplicado.
